goodreads.json: the schema, annotated

Field by field, as zod (apps/scrape/src/goodreads.ts) and CUE (cue/check-goodreads.cue) check it; their comments give each field's page elements, checks and transform. Examples are The Diamond Age (book 827, read 3 times) from the run of 2026-11-22.

[ { …one object per book on your shelves… }, … ]   // a plain array, in list order (last updated first); each object closed: these fields and no other, all required, so every entry has the same keys

1 · Identity

the key, and the links it carries
idlist"426793453" string, required: digits, ^\d+$
The key: the Goodreads review id (/review/show/<id>, the review page).
bookIdlist"827" string, required: digits, ^\d+$
The edition; no book id is listed twice.
workIdbook"2181158" string, required: digits, ^\d+$
All editions of the book: the book page's Work legacyId. Not the list row's /work/editions/<workId> link: rows with an empty format cell have none (3 on 2026-11-21). Entries of the same work are kept, one per edition; a run warns with the count of works with more than one entry.
bookURLlist"https://www.goodreads.com/book/show/827.The_Diamond_Age" string, required: a URL, ^https://www\.goodreads\.com/book/show/\d+
The book page, with its slug; can't be built from bookId.

2 · The book

what Goodreads says about it
titlelist"The Diamond Age: Or, a Young Lady's Illustrated Primer" string, required: not empty
The edition's title, with its series.
authorNamebook"Neal Stephenson" string, required: not empty
The primary contributor, as shown, spacing kept: two spaces in "Mark  Lawrence".
bookImageURLlist"…/books/1388180931l/827._SY75_.jpg" string, required: an https URL, ^https://
The list's small cover, or Goodreads' placeholder; can't be built from bookId.
isbnlist"0553380966" string, required: ^([0-9X]{10}|[0-9X]{13})?$, "" when none
numPageslist"499" string, required: digits, ^\d+$
"1,280 pp" → "1280"; "unknown" → "0".
averageRatinglist"4.2" string, required: ^\d\.\d$
The list's "avg rating" column, rounded to one decimal with toFixed(1) (4.05 → "4.0") only to avoid flapping. Not proven to be all editions' average: 1Q84 and Quicksilver differ per edition.
bookDescriptionbook"<i>The Diamond Age: Or, a Young Lady's…" string, required: HTML, may be ""
bookPublishedlist"1995-02" (shown "Feb 1995") string, required: "YYYY-MM-DD" (a real day) | "YYYY-MM" (month 01–12) | ^-?\d{4}$ | "" | the text as shown, never in a format the list shows and this normalizes, nor ISO-shaped like one
The work's original publication date, ISO 8601 at the precision shown: "Nov 05, 2023" → "2023-11-05" (865), "Jan 2027" → "2027-01" (151), "1995" (306), "100" → "0100" (2), "-750" → "-0750" (11; BC as Goodreads gives it, not astronomical), "unknown" → "" (123), an empty cell stays "" (never seen); counts of 2026-11-21. An impossible day fails the run; other text is kept as shown, with a warning (none on 2026-11-21).

3 · Your shelving

shelf, tags, rating, review
userShelflist"read" string, required: "to-read" | "currently-reading" | "read" | "did-not-finish" | "on-deck"
Goodreads' exclusive shelf, one and only one: the row's one ?shelf= link; equal to the review page's heading shelf. Each shelf's count is checked against the sidebar.
userTagslist[] string[], required: each not empty
Non-exclusive shelves, which Goodreads' UI calls tags: the row's ?tag= links, in row order; [] when none (Critique of Pure Reason: ["long-term"]). Exclusive or not is the link's own parameter, not a fixed list. Each tag's count is checked against the sidebar, as each shelf's is.
userRatinglist5 number, required: 0 to 5
Fractional as rated (4.25, 4.5); 0 is unrated, and a pre-release book is 0.
userReviewreview"" string, required: HTML, "" when none

4 · Your dates

all ISO 8601 UTC, but precision differs: a US Pacific day, as its start in UTC (read dates sometimes a month or a year, padded to the 1st); userUpdatedAt milliseconds, or a day on fallback
userAddedAtlist"2012-10-03T07:00:00.000Z" string, required: ISO 8601 UTC datetime
Date added, a Pacific day. A run warns (a count) when the timeline's one "Shelved" row of the entry's own edition has another day, or there is not exactly one (0 of 1458 on 2026-11-21).
userUpdatedAtbook review"2025-06-28T04:41:42.475Z" string, required: ISO 8601 UTC datetime
Best effort: close to Goodreads' "date updated" (the list's sort key), not exactly it; never proof of a change. The book page's updatedAt when present (to the ms); else the latest whole-day row of the entry's own timeline (a day); with neither, the run fails. Against the RSS of 2026-10-27: same day on 732/770 and 656/677. The file's order is the exact signal of what changed last.
userReadCountreview3 number, required: an integer, 0 or more
The entry's own "Finished Reading" rows, dated or not (rows ending "(… Edition)" are another edition's). The Great Code: 1, no dates. A run warns (a count) when the list's read_count differs (it is this + 1 on currently-reading), or a book on read has no finish.
userFirstReadAtreview"2012-11-23T08:00:00.000Z" string, required: ISO 8601 UTC datetime, "" when none is dated
The earliest dated own finish; "" when none is dated. A month or a year is padded to the 1st, and a 1st may stand for its month.
userLastReadAtreview"2025-06-27T07:00:00.000Z" string, required: ISO 8601 UTC datetime, "" when none is dated
As userFirstReadAt, the latest instead; equal to it with one dated finish.

5 · Timeline

the raw reading history behind the dates
timelinereview13 rows, first {"dateText": "October 3, 2012", "event": "Shelved"}, … {dateText, event}[], required; each row closed: dateText, string, ^(.* )?\d{4}$ or ""; event, string, not empty
Kept as shown, in page order; never empty on real pages. dateText is the text before the row's first en dash, its precision as shown ("October 23, 2026", "January, 1997", "2021"), "" when none. The provenance of userReadCount, userFirstReadAt, userLastReadAt and of userUpdatedAt's fallback.
